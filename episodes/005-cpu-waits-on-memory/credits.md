# Credits — 005 · cpu-waits-on-memory

Every third-party asset acquired for this episode, plus the licence it ships
under. Required before render (PLAYBOOK #8), gated by
`npx tsx scripts/check_credits.ts episodes/005-cpu-waits-on-memory`.

**Two things are true at once, and this file has to say both.** The gate joins
`assets.json` to this file on the asset's full posix path, so every *acquired*
path is written out verbatim below — including the four that no longer reach the
screen. But a viewer only ever sees what `src/` actually references, and three of
the screenshots ship as **crops** of the acquired original. So each entry names
the acquired file (the gate's join key), then what actually renders.

An earlier version of this file used shortened paths (`broll/…` instead of
`ep-cpu-waits-on-memory/broll/…`) and failed the gate on all ten assets while
being substantively complete — the paths below are the manifest's, exactly.

The render-path list was regenerated by grepping `src/` for `staticFile`
references, not by trusting the previous revision.

## Audio

Nothing in this episode's audio is third-party. There is no library music, no
sample pack and no stock SFX, so there is nothing here Content ID can claim.
Both entries below are reproducible from the commands given.

### `sfx/bed-005-continuous.wav`

Ambient bed, 620.000 s, 48 kHz mono, normalised to −28 LUFS (played at gain 0.14
in `Episode005.tsx`, i.e. ~−45 LUFS under the narration). Generated in-repo with
ffmpeg from `anoisesrc` brown noise plus three sine drones (55 / 82.41 / 110 Hz)
under slow independent LFOs, band-passed 32–560 Hz, with 6 s fades at both ends.
No third-party content of any kind, so no licence applies.

**ONE CONTINUOUS RENDER, NOT A LOOP.** This is the whole point of the file. The
composition is 18557 frames = 618.567 s and the bed is 620 s, so it is trimmed by
`SfxLayer`'s `endAt` and never wraps. ep003 looped a 20-second bed and produced
five audible silent seams at the joins; `SfxLayer` no longer has a `loop` prop at
all. Note the margin is now only **1.4 s** — the chunk-5 re-voice grew the
episode from 616.1 s to 618.6 s. Another beat of that size will overrun the bed
and reintroduce the seam, so regenerate it (change `d=620` and the `afade` start)
rather than letting it wrap:

```bash
ffmpeg -y \
  -f lavfi -i "anoisesrc=d=620:c=brown:r=48000:a=0.6" \
  -f lavfi -i "sine=frequency=55:duration=620:sample_rate=48000" \
  -f lavfi -i "sine=frequency=82.41:duration=620:sample_rate=48000" \
  -f lavfi -i "sine=frequency=110:duration=620:sample_rate=48000" \
  -filter_complex "\
[0:a]highpass=f=35,lowpass=f=300,volume=volume='0.80+0.20*sin(2*PI*t/97)':eval=frame[n];\
[1:a]volume=volume='0.30*(0.70+0.30*sin(2*PI*t/71))':eval=frame[d1];\
[2:a]volume=volume='0.17*(0.62+0.38*sin(2*PI*t/113+1.7))':eval=frame[d2];\
[3:a]volume=volume='0.09*(0.55+0.45*sin(2*PI*t/167+3.1))':eval=frame[d3];\
[n][d1][d2][d3]amix=inputs=4:normalize=0,lowpass=f=560,highpass=f=32,\
afade=t=in:st=0:d=6,afade=t=out:st=614:d=6,\
loudnorm=I=-28:TP=-9:LRA=6,aresample=48000" \
  -ar 48000 -ac 1 -c:a pcm_s16le -map_metadata -1 \
  public/sfx/bed-005-continuous.wav
```

### `narration.master.wav`

The ElevenLabs v3 clone read of this episode's script, mastered from
`narration.draft.wav` by `scripts/master_narration.sh` (two-pass ffmpeg
loudnorm). The voice is the channel's own cloned voice; no third-party
performance is used.

Measured **after** processing — single-pass loudnorm undershoots, so this is the
number that counts:

| Metric | Measured | Target |
|---|---|---|
| Integrated | **−15.2 LUFS** | −14 to −16 |
| True peak | **−1.5 dBTP** | ≤ −1 |
| LRA | 4.1 LU | — |
| Length | 618.560 s (29,690,880 samples @ 48 kHz mono) | — |

The raw draft measured −16.51 LUFS / −1.99 dBTP and was out of band. The
two-pass master preserved the sample count exactly, which is what keeps
`timing.json`'s word marks valid.

**Voice verified against the script, not assumed.** The finished master was
transcribed with whisper (`small.en`) and diffed against the narration: 1577
words, no ElevenLabs audio tag leaked into speech (the non-house `[surprised]`
cue in `modern_replication` is *performed*, not read aloud — whisper reads that
window as "14 years of smarter"), and the corrected facts "2021" and "14 years"
are both audible.
