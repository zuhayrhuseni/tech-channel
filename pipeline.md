# Pipeline

How a script becomes a video. Defines the handoff: the Claude Project writes
`script.yaml`, Claude Code consumes it. Tooling is Remotion (React-based
programmatic video — same code-driven paradigm as 3Blue1Brown's Manim,
better suited to typography/chart/UI-style motion graphics).

## Folder per video

```
episodes/002-two-job-markets/
  script.yaml         # narration + cues + visual spec — source of truth
  narration.txt       # generated by make_narration.py — teleprompter copy
  narration.wav       # 48kHz mono, -16 LUFS, metadata stripped
  narration.wav.json  # whisper-cli word timestamps
  timing.json         # generated by make_timing.py — every beat/mark in frames
  notes.md            # retention curve + what to fix, added after publishing
  out/                # renders — gitignored
```

Remotion scenes live in `src/` (shared component library + per-episode
scene files), not in the episode folder.

Gitignore `out/` and `*.wav`.

`script.yaml` is the only file written by hand. `narration.txt` is generated
and gets overwritten — never edit it.

## script.yaml schema

Narration and visuals live in one file. Split them and they drift, and the
animation ends up built for a line that was rewritten.

```yaml
title: Why adding an index can make your query slower
id: 001-index-slower
target_length: "10:00"

beats:
  - id: hook
    narration: >
      Adding an index makes queries faster. But there's a case where it
      makes the same query <mark id="slower"/>slower — and the index
      isn't broken.
    visual:
      build: [query_timer_fast, query_timer_slow]
      elements: 2
      land_at: slower

  - id: s2_close
    narration: >
      So the planner refusing your index isn't a bug. It's arithmetic.
    visual: none
    notes: SOURCE [2] — [VERIFY: confirm before recording]
```

**Fields**

- `narration` — spoken text. Contractions, one idea per sentence.
- `<mark id="x"/>` — cue anchor, placed *inside* the sentence on the exact
  word the visual illustrates.
- `build` — ordered list of elements revealed in sequence.
- `elements` — count of new things on screen; drives reading time at ~1s each.
- `land_at` — which mark the build starts on.
- `visual: none` — deliberate. Roughly a third of runtime carries no cue.
- `notes` — sources and `[VERIFY]` flags. Never spoken.

**A `#` inside a folded block (`>`) is literal text, not a comment.** Source
notes go in `notes:`, or they end up in the teleprompter.

## Sequence

1. **Write** `script.yaml`. 1,200–1,800 words for 8–12 minutes.
2. **Generate** `narration.txt` — `python3 make_narration.py <path>`.
3. **Read aloud.** Every stumble is a rewrite in the yaml, then regenerate.
4. **Record** tight, one continuous file. Snap fingers before re-reading a
   flubbed paragraph.
5. **Cut** bad takes. Duplicate text breaks alignment.
6. **Convert** — strip metadata, 48kHz mono, -16 LUFS.
7. **Animate** — Claude Code writes Remotion components (`src/`), renders
   per GOALS.md, and the render must PASS the `video-grader` agent.
8. **Publish**, then record the retention curve in `notes.md`.

Alignment is not a manual step. `whisper-cli` transcribes narration.wav with
word timestamps, and `make_timing.py` matches them to `<mark>` ids, writing
`timing.json` — the composition reads every cue frame from it. Re-recording
means regenerating `timing.json`, or every visual lands on a stale timestamp.

Record before animating. Animating first means re-recording every time a
build changes.

## Audio

```
ffmpeg -i raw.wav -map_metadata -1 -ar 48000 -ac 1 -af loudnorm=I=-16 narration.wav
```

Metadata stripping is an anonymity requirement — recording apps write device
and system usernames into audio files.

## Boundary

**Everything happens in Claude Code, in this repo.** Scripts are written
here with the `script-voice` skill and must pass the `script-grader` agent
before recording; the research corpus (`docs/research/`), strategy, and
script craft all live in the repo and load automatically.

(Historical note: script.yaml was originally authored in a Claude Desktop
project. That split ended 2026-08-25 — Desktop can't see the skills,
graders, or research corpus, so scripts written there bypass every quality
gate. Desktop remains fine for loose brainstorming, but the yaml is
written and graded here.)

One rule survives the merge: during a video *build* (animate/render),
script.yaml is frozen — a mid-build script edit invalidates the recording
and timing.json. Script edits happen in the writing phase, before
recording.
